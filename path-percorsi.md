In pratica contando un file "file.pdf" questi sono i significati dei percorsi prima di quel file

"" -> "file.pdf" : prendo il percorso dento
".\" -> ".\file.pdf" : prendo quello che c'è dentro la cartella ma è più fancy
"..\" -> "..\file.pdf" : va a prendere un file che è dentro la cartella sotto
